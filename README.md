# 🏢 Agente Corporativo de Inteligência Artificial

Bem-vindo ao repositório do **Agente Corporativo de IA**, desenvolvido como parte do desafio Alura Agentes!

## 📖 Sobre o Projeto
Este projeto traz a construção de um agente de Inteligência Artificial centralizado e aberto a todos os colaboradores de uma empresa hipotética. O agente atua como uma base de conhecimento conversacional, capaz de responder dúvidas consultando documentos internos de diferentes domínios organizacionais, como Recursos Humanos, Financeiro, Jurídico, Operacional e Estratégico.

O objetivo principal é eliminar silos de informação, garantindo que o conhecimento interno seja facilmente acessível através de linguagem natural.

## 🚀 Funcionalidades
* **Suporte Multi-formato:** Capacidade de ler e processar arquivos em PDF, Word, Excel, PowerPoint, Markdown, CSV, JSON e HTML.
* **Processamento de Linguagem Natural:** Respostas precisas e contextualizadas baseadas exclusivamente nos documentos fornecidos pela empresa.
* **Acesso Universal:** Disponível para todos os colaboradores sem necessidade de restrição de acesso por nível hierárquico.
* **Deploy em Nuvem:** Hospedado e executado na Oracle Cloud Infrastructure (OCI).
